# PG Life

PG Life is a web-based accommodation platform designed to help students and working professionals discover and explore suitable Paying Guest (PG) accommodations. The platform provides property listings, detailed property information, user authentication, and an easy-to-use interface for finding accommodation.

## Features

* User Registration and Login
* Browse PG accommodations
* Property listing page
* Detailed property information
* Search and explore available PGs
* User dashboard
* Responsive and user-friendly interface
* Structured property information

## How It Works

1. Users visit the PG Life website.
2. They can browse available PG accommodations.
3. Users can explore individual properties to view detailed information.
4. New users can create an account using the registration page.
5. Registered users can log in and access their account/dashboard.
6. The platform provides organized property information to make accommodation discovery easier.

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/nishapatwal/PG-life.git
```

### 2. Move the Project

If you are using **XAMPP**, move the project folder into:

```text
xampp/htdocs/
```

### 3. Start XAMPP

Open XAMPP and start:

* Apache
* MySQL

### 4. Configure the Database

Create a MySQL database and import the project's SQL file if provided.

Update the database configuration in the PHP configuration file with your:

```text
Database Name
Username
Password
Host
```

### 5. Run the Project

Open your browser and visit:

```text
http://localhost/PG-life/
```
